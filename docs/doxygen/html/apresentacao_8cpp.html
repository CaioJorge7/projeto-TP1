Descrição detalhada

Implementacao da camada de Apresentacao do sistema Kanban (TP1).

Dependencias desta unidade de compilacao:

  • apresentacao.h (e, por transitividade, interfaces.h, entidades.h, dominios.h)
  • Biblioteca padrao C++ (iostream, iomanip, limits, sstream, string, vector)

NUNCA inclui containers.h, sessao.h ou controladoras_*.h: a camada de apresentacao depende exclusivamente das 5 interfaces abstratas.

static

Le um inteiro do stdin e descarta o restante da linha.

Em caso de falha de extracao (entrada nao numerica), limpa o estado de erro e retorna -1. Se stdin estiver em EOF/erro, retorna 0 (sair/voltar).

◆ pausar()

static void pausar ( )
static

Em modo interativo (TTY), exibe "Pressione Enter..." e aguarda.

Quando stdin nao e um terminal (redirecionamento ou pipe), nao consome nenhum byte extra do buffer para evitar desvio de entradas automatizadas.
