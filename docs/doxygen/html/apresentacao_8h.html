Detailed Description

Camada de Apresentacao do sistema Kanban (TP1).

Esta camada depende EXCLUSIVAMENTE das cinco interfaces abstratas declaradas em interfaces.h. Nenhum cabecalho de controladora de servico (CS*) ou de containers e incluido aqui.

Estrutura:

  • ApresentacaoPessoa : CRUD de Pessoa (servicos 1-5)
  • ApresentacaoProjeto : CRUD de Projeto (servicos 6-10)
  • ApresentacaoQuadro : CRUD de Quadro (servicos 11-15)
  • ApresentacaoCartao : CRUD + mover + metricas de Cartao (servicos 16-26)
  • Aplicacao : Orquestrador; exibe menus raiz e delega aos sub-controladores de apresentacao.
