Detailed Description

Testes de unidade da camada de servico.

Cada servico do sistema (autenticacao mais os 26 servicos da tabela do enunciado) tem um caso de teste com cenario de sucesso. Alguns casos tambem conferem uma falha tipica (por exemplo, papel sem direito ao servico).
