19// Decisao de projeto: armazenamento em memoria com std::map (permitido pelo
20// enunciado, requisito 23). Cada container guarda um tipo de entidade,
21// indexado pela chave primaria em texto (getValor()).
22// Decisao de projeto: as entidades ja trazem os vinculos (gestorEmail,
23// projetoId, quadroId, desenvolvedorEmail), entao os containers nao guardam
24// vinculos a parte. As buscas por vinculo (contar...) varrem o mapa.
25// Decisao de projeto: as entidades nao tem construtor padrao, entao pesquisar
26// devolve ponteiro (nullptr se nao existe) em vez de preencher um objeto.
27// O ponteiro vale ate o proximo incluir/remover; copie o objeto se precisar
28// guardar.
29// Decisao de projeto: incluir devolve false se a chave ja existe; remover e
30// atualizar devolvem false se a chave nao existe.
