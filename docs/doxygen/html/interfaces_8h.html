Descrição detalhada

Contratos abstratos entre Apresentacao e Servico para o TP1 Kanban.

A camada de apresentacao depende somente destes contratos. Os metodos serao implementados pelas controladoras da camada de servico (Membro 3). Os papeis, multiplicidades, WIP e regras de estado sao verificados no servico. As falhas de validacao/integridade devem ser comunicadas por excecoes.
